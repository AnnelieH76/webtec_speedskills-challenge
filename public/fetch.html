Uppgift: Fetch API

I denna uppgift används Fetch API för att asynkront hämta extern data över HTTP och presentera den i en dynamisk HTML-tabell. Applikationen jämför koldioxidutsläpp över tid för Sverige, Norge och Danmark baserat på öppna data från Our World in Data (OWID).

Koldioxidutsläpp

Country Co2 (million tonnes) Co2 per capita (tonnes per person) Oil Co2 (million tonnes)
