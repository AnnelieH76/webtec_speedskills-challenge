# SpeedSkills Challenge 🏁

Det avslutande kursmomentet resulterade i ett interaktivt webbspel och responsiv onepage-webbplats inspirerad av klassiska arkadspel, byggd från grunden med semantisk HTML5, ren CSS och JavaScript.

---

## 🛠 Tekniker & Arkitektur
- **HTML5:** Semantisk struktur, W3C-validerad markup.
- **CSS3:** Flexbox, Grid, CSS-variabler samt orienteringshantering för mobila skärmar.
- **JavaScript (ES6+):** Objektorienterad tillståndshantering (`gameObject`), DOM-caching och dynamisk koordinatberäkning.

---

## 🎮 Funktioner
- Interaktiv spelyta med dynamisk HUD (poäng, tid, träffar).
- Orienteringsspärr som guidar användare till landskapsläge på mobila enheter.
- Justerbara svårighetsgrader och anpassad banlayout.
